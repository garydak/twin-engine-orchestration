# 双星协同工作流技能指南 (Twin-Engine Skill)

使用本技能在同一个会话中实现高级中转模型与原生执行工具的无缝协同。

## 适用场景
- 复杂业务模块重构与技术选型
- 高难度算法与数据流设计
- 并发/网络竞态 Bug 深度诊断
- 安全审计与代码终审 Review
- 官方高级模型额度耗尽时的无缝续航

## 协同标准动作
1. **分析现状**：主智能体使用原生 `read_file` 收集关键代码与错误日志，提炼问题。
2. **智囊咨询**：调用 `api-model-switcher-mcp` 的 `chat_with_custom_model` 工具，将提炼好的架构任务提交给中转站模型获取深度推演。
3. **原生落地**：主智能体依据回复，使用原生的 `edit_file` 和 `run_command` 进行代码修改与自动化测试。
4. **验证汇报**：验证通过后在当前窗口展示成果。

# 架构脑专用提问模板 (Architect Prompt Templates)

主智能体在向架构脑（中转高级模型）请教时，可使用以下结构化模板提炼上下文，以保证最高质量的架构推演：

---

## 模板 1：复杂业务重构与状态机设计

```markdown
【任务类型】：架构重构 / 状态机设计
【当前背景与挑战】：
- 当前代码位于 `<filepath>`，负责 `<模块职责>`。
- 现有实现的主要瓶颈/痛点是：`<例如：状态分散，容易出现并发漏单或状态回滚异常>`。

【关联核心类型/接口】：
```typescript
<粘贴核心数据结构与接口定义，不超过 80 行>
```

【期待架构脑提供】：
1. 状态转移矩阵与异常边界防范策略。
2. 推荐的目录划分或类/函数抽象设计。
3. 关键实现伪代码或核心实现函数。
```

---

## 模板 2：疑难并发/网络竞态死锁排查

```markdown
【任务类型】：并发排错 / 竞态条件排查
【故障现象】：
- `<报错信息或偶发失效现象>`
- 最小复现路径或高并发压测场景。

【关键调用栈与代码段】：
```typescript
<粘贴涉及并发读写的代码段与锁机制>
```

【期待架构脑提供】：
1. 产生竞态/死锁的根因时序分析（Sequence Diagram 逻辑）。
2. 无锁/细粒度锁/队列化改造方案。
3. 针对性的补丁代码与防退化单测编写建议。
```

---

【任务类型】：代码终审 / 安全审计
【待审模块】：`<模块名称及主要输入输出>`
【变更代码片段】：
```diff

```

【期待架构脑提供】：

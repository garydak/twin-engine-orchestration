# 双星智能体协同：系统全局智能体规则 (Twin-Engine Global Agent Rule)

本规范定义在 Antigravity、Cursor 及各类 AI Agent 运行时环境中的跨模型协同行为。

## 一、双引擎协同核心定义
- **大脑 (Brain)**: 专注“思考”。深度推理、技术选型、逻辑纠错、方案推演。由外挂的顶级中转模型担任。
- **手脚 (Hands)**: 专注“行动”。环境探测、文件读写、控制台编译、单元测试。由持有原生系统级工具的主智能体担任。

## 二、自动协作与无缝衔接准则
1. **同会话无缝桥接**：
   - 当调用外部架构模型时，上下文应平滑传递，主智能体将架构脑的分析结果转化为工程 Diff 动作，无需用户在不同聊天窗口手动复制粘贴。
2. **免额度焦虑 (Zero-Quota-Anxiety)**：
   - 官方订阅额度充足时，可全量使用官方模型；
   - 官方高级额度告罄（0%）时，自动将主引擎切换至轻量/无限量模型充当“手”，架构推演请求由中转模型充当“脑”。
3. **闭环落地责任制**：
   - 架构脑输出的代码方案，主智能体必须接管落地（使用 `edit_file` / `write_file`），并主动执行语法检查或单元测试（`run_command`），测试成功后方可结项汇报。
